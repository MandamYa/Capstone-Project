Tujuan Aplikasi

**NASI-BARAS** (Navigasi & Sistem Informasi Bantuan Rakyat Miskin) adalah sistem manajemen data yang dirancang untuk mempermudah instansi atau lembaga dalam mengelola, memfilter, dan memvalidasi data penerima bantuan sosial. Sistem ini bertujuan meningkatkan **efisiensi penyaluran** dan **akurasi target** bantuan.

Fitur Utama

  • Integrasi data cepat melalui *upload* file **Excel (.xlsx)**.
  • Pencarian dan pemfilteran data penerima berdasarkan wilayah (RT/RW/Kelurahan).
  • Fitur navigasi berbasis lokasi (asumsi data koordinat tersedia) untuk verifikasi lapangan.

Informasi Teknis

Aplikasi ini dikembangkan menggunakan teknologi *frontend* murni **HTML5, CSS3, dan JavaScript (Vanilla JS)** untuk memastikan kecepatan akses dan kemudahan implementasi tanpa ketergantungan *server* yang kompleks.

1. Muat Data Excel

Langkah 1.1 - Unggah Data: Gunakan tombol 'Pilih File Excel' atau area Drag & Drop untuk mengunggah file data (.xlsx). Tombol 'Unduh Template' tersedia jika Anda membutuhkan format data standar.

2. Mencari & Menampilkan Data

Langkah 2.1 - Pencarian & Tabel: Masukkan nama penerima di kolom pencarian dan klik ikon kaca pembesar () untuk mencari. Navigasi halaman menggunakan tombol panah di bawah tabel.

2.2 Filter Wilayah

Langkah 2.2 - Buka Filter: Klik tombol 'Filter Wilayah'. Pilih kriteria (Wilayah/RW/RT) dari dropdown lalu klik 'Tampilkan Data'.

2.3 Hasil Filter Aktif

Langkah 2.3 - Status Filter: Ringkasan filter yang diterapkan akan muncul di atas kolom pencarian. Klik tombol 'Reset' (merah) untuk menghapus semua filter.

3. Melihat Detail Biodata

Langkah 3.1 - Buka Biodata: Klik nama penerima pada tabel untuk menampilkan Modal Biodata. Tinjau Jenis Bantuan dan Alamat Lengkap.

3.1 Navigasi ke Lokasi

Langkah 3.2 - Navigasi: Klik tombol 'Navigasi' di Modal Biodata. Kemudian konfirmasi 'Ya, Navigasi' untuk membuka aplikasi peta menuju lokasi.
